## Directory Layout

```text
exercicio/
├── CMakeLists.txt
├── src/
│   ├── main.cpp
│   ├── solver.cpp
│   └── solver.hpp
└── build/          (Generated by CMake; do not commit to git)
    └── exercicio   (Compiled binary)
```

## CMake

CMake manages the build process of C++ code. It does not compile code directly.
Instead, CMake generates native build scripts for your compiler.

- **Configure step (`cmake -B build`)**: Reads `CMakeLists.txt`, checks your compiler, and generates build files in the `build/` directory.
- **Build step (`cmake --build build`)**: Invokes your compiler to turn your source code into a runnable executable.

## Commands

1. **Configure** (run once, or when you edit `CMakeLists.txt`):

   ```bash
   cmake -B build
   ```

2. **Build** (run each time you edit `.cpp` or `.hpp` files):

   ```bash
   cmake --build build
   ```

3. **Run**:

   ```bash
   ./build/exercicio_02
   ```

## How to Reset / Clean Rebuild

If cache files get corrupted, delete the `build/` folder and reconfigure:

```bash
rm -rf build
cmake -B build
cmake --build build
```
