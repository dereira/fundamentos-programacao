# padaria

A padaria Castelão vende diariamente uma determinada quantidade de pães e de broas. Cada pão custa 0,14 €
e cada broa custa 1,50 €. No final do dia, o proprietário pretende saber o valor total obtido com a venda
destes produtos. Desenvolva um algoritmo que leia a quantidade de pães e de broas vendidas num dia e calcule
o total arrecadado, em euros.
